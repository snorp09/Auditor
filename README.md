# Auditor
An expense tracking app, designed to help keep track finances for others.

## About
Auditor is an application, written using C#, ASP.NET, and Razor pages, meant for helping tracking expenses for people who are no longer capable of doing it for themselves.


I'm writing this program, in part due to potential need of my own in the future, but also as an excuse to teach myself full-stack development, not just APIs. The project is structured into the following mile stones:

#### Example Use case(s)
If you want to monitor where someone vulnerable's money is going, you can set up a personal accountability system, built upon making sure transactions are cataloged using the Auditor software, so you can review making sure everything looks correct.

If your parents are no longer capable of tracking their own money, you can set up monitor, to keep them in the loop, as you take over.
